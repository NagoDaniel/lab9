# lab9: FC Barcelona 2009/10 passzhálózatok

Gráfelmélet labor: a Barcelona 2009/10-es La Liga-szezonjának passzhálózatai.

- `FELADAT.md`: a C++ feladat leírása (`skeleton.cpp` a váz, `passes_clean2.csv` a bemenet)
- `PYTHON_VIZ.md`: adatok betöltése, ábrák és hálózatok Pythonban
- `DATA.md`: a CSV fájlok oszlopainak leírása

## Forrás

Az adatok a [StatsBomb Open Data](https://github.com/statsbomb/open-data) nyilvános adatkészletből származnak,
feldolgozva. Felhasználásukkor jelölni kell a StatsBomb forrást.
Háttér: Buldú et al. (2019), a passzhálózatok elemzése.
